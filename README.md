## What Is Published Here vs. Kept Private

- **Published in `pal-spec`:**
  - The normative wire protocol specification (`spec/v3/PAL-3.0.md`): byte-exact TLV encodings, 1-RTT identity-protected SIGMA-I hybrid post-quantum handshake, hybrid KEM combiner (HKDF-SHA-384 over both shared secrets and the key-exchange context), `ChaCha20-Poly1305` records with a 20-byte header, domain-separated `SHA-384` 256 KiB Merkle tree equations, capability grant evaluation order, `PAL-EXT-SIG-V3` extension bundle signing, and `diag.v1` diagnostics.
  - Deterministic byte-exact conformance test vectors (`test-vectors/v3/pal3-v0.5-vectors.json`) and zero-dependency validator (`validate.mjs`).
  - Vector coverage today: TLV, comprehension bits, key schedule, record AEAD, identity digest (v0.5); SHA-384 and identifiers, Merkle trees, stateless cookie and PoW, resumption binder, manifest revision, swarm decisions, busy clamp, relay tree, negotiation, pair beacon, signed prekey, stateless reset, mailbox location key, private network profile, `onion/2` relay cells, rekey, C2 packet and header protection, Quick Drop SAS and handshake SAS, `SEALED_HELLO`, signed grants, extension bundle signing the pre-SHA-384 device certificate stored-state migration, chunk-group outboards, private share encryption, device certificates and revocation, the version and suite registry, and plaintext bulk records (v0.6). The rekey, header protection, SAS, `SEALED_HELLO`, grant, extension signing, chunk outboard, private share, device revocation, registry and plaintext record files are generated by `bin/generate-v0.6-<name>-vectors.mjs --pal-core <pal-core checkout with dependencies>`; the grant and extension files are signed in the deterministic ML-DSA mode so two runs are byte-identical. Every vector area of the specification has at least one file. [`test-vectors/v3/COVERAGE.md`](test-vectors/v3/COVERAGE.md) maps each normative section to its vector files and case ids, and `test/coverage-table.test.mjs` fails when a section is missing from it.
- **Strictly Proprietary (Not Published):**
  - The Palexplorer desktop/CLI/mobile applications, `pal-core` runtime engine, adaptive multi-source scheduler, and discovery/rendezvous server implementations remain closed-source and proprietary.

Requires Node.js 24.7+ (zero external npm dependencies):

```bash
npm run validate
npm test
```
